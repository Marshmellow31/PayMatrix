# paymatrix 1.2.5

Android reliability, UI, safe-area, and smoothness release.

## Fixes and improvements

- Restores reliable friend-request writes after Android resume by waiting for Firebase Auth restoration, refreshing the ID token, retrying transient Firestore failures, and treating an already-pending request as idempotent success.
- Deploys the matching Firestore authorization rules, including secure reconnects after a rejected or previously accepted request.
- Uses a single-tab Firestore cache inside the APK to avoid unnecessary IndexedDB tab coordination.
- Uses the real display cutout/status-bar inset with a compact 64 px native toolbar instead of adding a hard 24 px spacer to an 80 px header.
- Selects the highest refresh-rate display mode at the device's current resolution on Android 6+, while retaining Android 15+ high-frame-rate category requests.
- Keeps hardware acceleration enabled and removes expensive native header/footer backdrop filtering.
- Includes the refined monochrome dashboard, account card, navigation, and friend-lookup UI.

## Permissions

The final APK requests only Internet/network access, notifications, vibration, wake lock, and Firebase messaging receiver permissions. Bill capture uses Android's system camera/file chooser only after the user taps **Scan bill**, so the app does not request broad camera or storage access.
