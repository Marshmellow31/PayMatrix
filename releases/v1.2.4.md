# paymatrix 1.2.4

Android compatibility release for existing and first-time installations.

## Fixes

- Keeps valid Google authentication authoritative when optional profile refreshes fail.
- Supports legacy profiles without weakening validation for newly changed avatar URLs.
- Uses permitted exact friend-request reads instead of private pre-friend profile reads.
- Removes rejected client-side security-log writes and their misleading console warning.
- Includes the current Android-safe bottom navigation.

## Install or update

Open `paymatrix-1.2.4.apk` on Android. It uses package `com.paymatrix.app`, build `10204`, and the same release certificate as 1.2.3, so it can update 1.2.3 in place or install on a device that does not have paymatrix.

If Android reports a signature conflict, the installed copy came from a differently signed debug or unofficial APK. That copy must be removed before installing this release; Android cannot safely update across signing identities.
