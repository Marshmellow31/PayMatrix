# paymatrix 2.0.2

This native Android update focuses on visual parity and profile-photo reliability while retaining the production package, Firebase backend, account data, and signing identity.

## Improvements

- Exact web Digital Obsidian surface colors instead of the near-black native canvas
- Redesigned Friends screen with Nodes/Signals tabs and compact web-style cards
- Redesigned Logs screen with web typography, Create Group action, divider, and timeline cards
- Added Coil's OkHttp network transport so Google and Firebase Storage profile photos load
- Preserved `avatar` and `photoURL` compatibility with domain validation and cached fallbacks
- Version `2.0.2` (`20200`) for a normal in-place upgrade from v1.2.5 and v2.0.1

## Please note

This release may contain bugs. Report issues at https://github.com/Marshmellow31/PayMatrix/issues with the phone model, Android version, affected screen, and reproduction steps.
