# paymatrix 2.0.1

This is the native Kotlin/Jetpack Compose Android release. It upgrades the existing `com.paymatrix.app` installation from v1.2.5 and continues using the same Firebase backend and accounts.

## Highlights

- Native screen rendering and navigation
- Screenshot-aligned dashboard, friends, groups, and group detail design
- Google profile photos in the header, profile, friends, members, and group stacks
- Fixed Home navigation after switching tabs
- Production package, Firebase configuration, signing identity, and v1.2.5 launcher artwork
- Administrator panel and privileged client operations removed
- Compact bottom navigation and restored Create group / Join controls

## Please note

This release may contain bugs. If you find one, please report it at https://github.com/Marshmellow31/PayMatrix/issues with your Android version, phone model, the screen involved, and steps to reproduce it.

Payment safety is unchanged: opening a UPI app does not prove payment. Confirm the successful transaction in the UPI or bank history before recording a settlement.
