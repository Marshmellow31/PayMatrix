# paymatrix Android

Native Kotlin/Compose shared expense ledger for friends, roommates and trips. Users need to record a bill, understand each share, and confirm settlement. This is an Operate surface. Preserve package com.paymatrix.app, logo.png, verified email/Google authentication, integer paise and QR fallback. A payment app return does not prove settlement.

The user approved implementation and release on 2026-09-08: softer obsidian, reference-inspired warm light theme, matching navigation, understandable item splitting, local reminders and a widget.
