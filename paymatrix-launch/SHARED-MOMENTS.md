# Shared Moments — production notes

## Run
From this directory: `npm.cmd start`, select `paymatrix-Shared-Moments`.
`npm.cmd run typecheck` checks TypeScript. `npm.cmd run render` produces
`renders/paymatrix-Shared-Moments.mp4` (28 seconds, 1080 × 2400, 60fps).
`npm.cmd run render:legacy` renders the original composition.

## Ownership
`src/premium/data.ts`: frame ranges and fictional integer-paise fixture.
`src/premium/Product.tsx`: production-based presentation adapters with inert actions.
`src/premium/Film.tsx`: compositing, phone shell, receipt, typography and motion.
`scripts/make-soundtrack.py`: original deterministic standard-library synthesized score.
`public/fonts`: Manrope and Inter with their OFL license notices.

## Evidence and boundaries

BillScannerModal.jsx and SettleUpModal.jsx. These are adapted views, not pixel-identical
recordings. No authenticated network calls or writes. One bill: 428000 paise,
four 107000-paise shares, three obligations totaling 321000 paise. QR uses a
non-payment demonstration string and is labeled. No payment success is depicted.

No Blender execution or existing rendered Blender plates are used. No external music
or sampled audio: the accompanying score is generated by the included script. Font
licenses are bundled. Website availability was checked; Play distribution was not claimed.
